LM Studio Setup Guide

Run a local model completely free — no API key, no internet needed. Three steps.

STEP 1 — Download & install LM Studio
Download for free from lmstudio.ai (Mac / Windows / Linux). Install and open it.
STEP 2 — Download a model & start the server with CORS enabled
In LM Studio → Discover tab, search for and download one of these (pick by available RAM):
★ Best quality Qwen3-14B-Instruct-Q4 ~9 GB RAM
★ Balanced Qwen3-8B-Instruct-Q4 ~5 GB RAM
★ Low RAM Qwen3-4B-Instruct-Q4 ~3 GB RAM
Also works Llama-3.2-3B, Mistral-7B, Phi-4-mini
Then go to the Developer tab (left sidebar):
1. Click Start Server
2. Find the toggle "Allow cross-origin requests (CORS)" → turn it ON ← this is essential!
3. Server URL should show http://localhost:1234
STEP 3 — Open SuspenseLens correctly & connect
⚠ Do not double-click the HTML file — open a Terminal in the same folder and run:
python3 -m http.server 8080 Then open http://localhost:8080/SuspenseLens.html in your browser.

Back in SuspenseLens: Backend = LM Studio · URL = http://localhost:1234 · click Test ↗
